# alpp.studio

alpp.studio web sitesi. GitHub Pages ile yayınlanır (`main` dalı, kök klasör).

- `index.html` — ana sayfa, uygulama listesi
- `mandirake/` — Mandırake destek ve gizlilik sayfaları
- `monsite/` — MonSite destek ve gizlilik sayfaları
- `CNAME` — özel alan adı (`alpp.studio`)

Yeni uygulama eklemek için: `<uygulama>/index.html` (destek) ve `<uygulama>/privacy/index.html` (gizlilik) oluşturup ana sayfaya bir kart ekleyin.
